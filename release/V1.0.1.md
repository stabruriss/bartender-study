# Reproduction package v1.0.1

This documentation release reorganizes the root README into title, description,
dataset, code, usage, requirements, methodology, citations and contribution
sections. It adds explicit commands to reproduce result figures, independently
verify plotted values and regenerate external workload range-positioning tables
from released inputs.

The accepted simulation, application observations, deployment data, external
workload counts, analysis code, configurations, seeds and execution protocol are
unchanged. This release does not rerun experiments or revise scientific results.
The complete historical method descriptions and the v1.0.0 archive verification
remain available.

The code/technical-documentation license remains MIT, and study data/figures
remain CC BY 4.0; see the root LICENSE for separate third-party and manuscript
terms. The software ZIP includes raw-archive indexes and checksums, not the
separately hosted raw bytes.

The tag snapshot's CITATION.cff uses the software concept DOI
10.5281/zenodo.22820986 because the version DOI is minted after release
publication. Once minted and verified, the branch metadata and a version-specific
archive verification record will identify that DOI without moving this tag.
The article's preferred citation remains 10.5281/zenodo.22802897.
