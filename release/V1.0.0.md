# Bartender reproduction package v1.0.0

This snapshot accompanies the preprint
[10.5281/zenodo.22802897](https://doi.org/10.5281/zenodo.22802897).
It provides the synthetic model, fixed 990-cell configuration and 30 seeds,
accepted 29,700-run aggregates, paired contrasts, deterministic analysis and
plotting sources, point-level provenance, application conformance records,
deployment data and methods, and external workload scenario range positioning.

The accepted original data and execution approvals are unchanged. The initial
verification HOLD and the separately approved verify-02 PASS remain available.
The external positioning retains its 31 source-unavailable rows and one current
404; it is not calibration or validation of the synthetic model.

## Reproduce and inspect

- Study model and controls: `README.md`, `tests/`.
- Figures and tables from accepted aggregates: `analysis/README.md`.
- External positioning: `analysis/calibration/README.md` and `VALIDATION.json`.
- Provenance, deployment data and source audit: `release/RELEASE_CHECKLIST.md`.
- Citation and reuse scopes: `CITATION.cff` and `LICENSE`.

The source ZIP is a snapshot of tracked files at the release commit. It contains
no `.git` history, virtual environment, local execution logs or raw archive
parts. `release/arxiv/` preserves the historical v1 manuscript source, not the
later journal submission. The current research additions are available in the
analysis directories.

The four raw archive parts remain at the public locations in
`release/RAW_ARCHIVES.json`, with individual and concatenated SHA-256 values.
The independently verified concatenated archive is 4,200,591,360 bytes,
SHA-256 `2256b0bf734992aa37d1a59f176832f08cce8946fc514dee4f8b87d37e625beb`.
The software ZIP archives the index, not those raw bytes.
