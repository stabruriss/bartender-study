# Execution report location

The authoritative generated report belongs at
`deliverables/study-01/RUN_REPORT.md`. Follow `RUNBOOK.md`; do not copy the delivery
to this root index or write an independent results summary. Consult the actual
approval and validation files for execution readiness; this index is not a run
status record.

Required contents: exact plan/digests and source revision; runtime and hardware
description without local identifiers; UTC start/end and measured wall time;
completed/failed counts; all deviations; control/determinism/verification records;
repository-relative output/archive locations and archive hashes. Do not include
scientific interpretation or personal context. Numerical values come only from
the supplied `handoff.py` output files.
